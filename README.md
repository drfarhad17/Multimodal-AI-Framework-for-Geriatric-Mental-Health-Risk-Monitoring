# Multimodal AI Framework for Geriatric Mental Health Risk Monitoring

## Overview
This repository accompanies the manuscript:
“Explainable Multimodal AI Framework for Geriatric Mental Health
Risk Monitoring: A Simulation Study.”

The study explores the integration of physiological, behavioral,
sleep, mobility, speech, and conversational information for
simulation-based mental health risk assessment in older adults.

## Study Design
The manuscript describes a proof-of-concept simulation using
the Synthetic Multimodal Geriatric Mental Health (SMGMH) dataset.

The reported dataset comprises:
- 2,000 simulated participants.
- 20,000 monitoring sessions.
- 10 observations per participant.
- Simulated ages ranging from 60 to 90 years.
- Five reference-label categories: normal, depression, anxiety,
  cognitive decline, and dementia.

These specifications describe the manuscript's simulation.
They do not represent clinically collected patient data.

## Dataset and Code Availability
This README provides an overview of the study.

## Intended Use
The project is intended for research and methodological evaluation
of multimodal AI under simulated conditions.

The synthetic labels are not clinical diagnoses. The framework
requires independent clinical validation before use in patient care.

## Reproducibility
A complete reproducibility package should include:
- Synthetic data generation code and random seeds.
- Dataset files and a data dictionary.
- Participant-level training, validation, and test splits.
- Software dependencies and version information.
- Commands for running preprocessing, training, and evaluation.
- Outputs supporting the results reported in the manuscript.
